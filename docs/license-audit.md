# License review — 2026-10-30

The repository's original source is Apache-2.0. `LICENSE` contains the full text. Source and configuration files carry SPDX notices where syntax permits; JSON files use a `license` field or are covered by this repository notice.

`npm run check:licenses` reviews every dependency entry in `package-lock.json` (including optional platform packages). The current lockfile reports MIT, ISC, Apache-2.0, BSD-2-Clause, BSD-3-Clause, or `(MIT OR Apache-2.0)` for `@maplibre/mlt`. These are OSI-approved license options. The script accepts only these exact metadata values and fails on any new/unknown license so it receives manual review. This is a metadata-level check, not a legal opinion or a source-by-source audit of embedded assets.

The portal does not include iHanoi artwork, logos or data, and no external service SDK. It uses local system fonts and Lucide icons (ISC). The staff report map uses [MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js) (BSD-3-Clause) and requests interactive raster tiles from OpenStreetMap's standard tile server by default, with visible OpenStreetMap attribution. The tile URL is configurable with `VITE_MAP_TILE_URL`; a deployed or high-traffic installation needs an appropriate tile provider and must follow the [OpenStreetMap tile policy](https://operations.osmfoundation.org/policies/tiles/) or that provider's terms. The map does not bundle map data or official city records. Future map data, official APIs and external service content require separate provenance and terms checks before publication.
